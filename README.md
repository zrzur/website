# Zrzur website

The website of [Zrzur](https://zrzur.com), built with Solid.js, TypeScript and Vite.

```bash
git clone https://github.com/zrzur/website.git
cd website
npm ci
npm test
npm run build
npm run preview
```

Needs Git and Node.js 24. Preview: http://127.0.0.1:14826/. Development: `npm run dev`. Static output is in `dist/`, and hosting needs an SPA fallback. Optional public URLs go in `.env.local`; see `.env.example`.
